# 神经形态计算 · 技术思维 #9：迁移到正明

## 两性费曼 · 性一（12 岁也能懂）
- **这是什么**：像把健身房私教的方法搬回自己家练——你不必买下那台昂贵的器械，真正值钱的是"哪块肌肉该在什么时机发力"这条规矩。哪里不像：肌肉累不累有酸痛可以衡量，人脑的消耗没有仪表，只能靠自己的状态去感觉，所以这条规矩既更难坚持，也更容易自我欺骗。
- **与我何干**：**省钱**。搬过来的对象是"设计规矩"（只报变化、容忍 80 分、学习发生在数据所在地），不买硬件、不改技术栈，成本就是两小时的纸面工作，收益落在调用次数与自己的注意力上。
- **我该怎么办**：在看板里建一个"迁移"专区，四列：事件化改造 / 两层架构 / 学习栈分层 / 成本事件化。每列先填已知项，再各留三个空位。两小时内只做落点登记，不写代码。

## 两性费曼 · 性二（同行可验证）
- **机制**：迁移的合法性来自"原语同构"而非修辞类比——芯片侧的事件驱动、稀疏 + 容差、本地学习、混合架构四个原语，在软件信息系统里各有对应物（只报变化的摄入层、注意力与交付纪律、本机自适应层、监听层 + 思考层），因为两侧同处"数据 / 事件 / 规则 / 调用"这一抽象层。经济侧的硬约束是接口按次计费，等价于按搬动的比特付费。
- **边界数**：功耗锚点 Loihi 2 芯片级 <1W、Akida 30mW、Speck 空闲 <1mW、TrueNorth 70mW [二手]；能效锚点 10×-1000× 需三条件同时成立 [二手]；DVS 微秒级延迟、DAVIS240 于 2021 年随 Falcon Neuro 项目上过国际空间站 [二手]；改造顺序为事件化→两层化→分层化 [推算]。
- **反例**：①若当前调用量与时间开销本就极低，事件化收益低于改造本身的时间成本（先量化再动手）；②若业务进入需要大规模密集计算的阶段，事件驱动纪律部分失效；③若把"同构"当成教条——芯片省的是焦耳、可用仪表测，人省的是注意力、只能自省，二者只是部分同构。
- **可复现**：按 #6 的两小时账本先测出基线（月度调用次数与时间开销），完成事件化改造后隔月再测一次，比较单位业务产出的调用次数；同时记录误触发率，防止省了调用却丢了召回。

## 一句话（费曼层）
善伦不一定需要一块神经形态芯片——但「从算力堆砌到事件驱动」的思维转换，对正明系统是一次零成本的升级。

## 为什么这条路线被低估
前沿技术介绍文字的默认写法是「它多大多快多新」，读者看完热血三分钟，然后该干嘛干嘛。把异域技术的「约束」转译成自身系统的「设计纪律」——这个动作没有报道价值，所以很少有人系统去做。

但对善伦这个特定身份——一人公司创始人 + 自建 AI 系统 + 三种内容创作——这个动作是杠杆率最高的：不用买硅片，不用改技术栈，只用芯片背后的物理约束倒逼自己的系统设计。巨头看不上这种「软迁移」，一人公司恰恰只剩这条路可走。

## 第一性原理拆解
迁移的第一性是「原语同构」：神经形态的几个核心原语，在善伦的信息系统里各有一个对应物。

原语一，事件驱动（DVS 只传变化）→ 对应物：善伦系统的信息摄入只报变化。定时轮询是全量帧思维；变化触发是事件思维。物理约束：API 调用按次计费——每多轮询一次，就是多搬一次零信息量的数据。

原语二，稀疏+容差（三条件省 100×）→ 对应物：善伦的注意力与交付纪律。多数事务多数时间不该占用「重度处理」；80 分的交付在多数场景够用。物理约束：善伦的时间与资金是真正的稀缺资源，比任何芯片的功耗都硬。

原语三，STDP 本地学习（标签不出传感器）→ 对应物：善伦系统的本地自适应层。客户行为、个人写作风格、操作习惯——这些数据不该出本机，学习该发生在数据所在的地方。

原语四（架构层），混合架构（神经形态听、GPU 想）→ 对应物：正明的两层设计（监听层+思考层，#8 已展开）。

几条对应关系成立的前提：善伦的系统是「信息系统」——数据、事件、规则、调用，与芯片的「脉冲、突触、学习」在同构的抽象层上。这也是为什么本篇的迁移不是类比修辞，是工程同构。

## 技术机制与关键事实
本篇是系列的集成篇，引用前八件的事实包数据做迁移锚点，不重复展开：

- 功耗锚点：Loihi 2 芯片级 <1W；Akida 30mW；Speck 空闲 <1mW；TrueNorth 70mW。善伦的系统预算也分级：常开层追求「近零」，按需层追求「单位产出」。
- 能效锚点：10×-1000× 只在三条件同时成立时出现（#6）——善伦的降本同样三条件：稀疏任务、事件输入、容忍近似。
- 传感锚点：DVS 无空闲帧、微秒级延迟、DAVIS240 上过国际空间站（#4）——善伦的店铺/物流/舆情监控就该是这个响应曲线。
- 训练锚点：三条路线（#3）——蒸馏（①）、微调（②）、本地自适应（③）构成善伦系统的完整学习栈。
- 硬件锚点（#5）：善伦当前一张芯片都不用买，但要保留「任务结构匹配」的选型纪律。
- 软件锚点（#7）：贴着 API 而非贴着金属，是一人公司的正确生态位。

按业务线拆开，迁移落点：

跨境电商：①店铺异常监控（库存、价格、物流、评价）从定时巡检改事件触发——只报变化；②竞品价格追踪只记变化点，变化点才触发分析；③监控报表容忍近似——能触发决策的精度即可，不需要全量实时精确。三项都是「事件驱动+容忍近似」的直接应用。

AI 音乐：①音频前端事件化——onset/节拍检测优先于逐样本分析；②灵感素材库设「关联触发」——新素材与既有项目产生语义关联时才提醒，不做每日全库扫描；③生成环节该上 GPU 上 GPU（那是密集计算的正确区间，别为叙事省钱）。

小说创作：①设定「触发式写作」——灵感片段的关联网络变化时推送，替代每日翻阅素材库；②初稿容忍 80 分（容差条件），完稿期才上重思考；③连载节奏的时间结构设计（#2 的文学同构）。

正明 AI 系统（集成）：①信息摄入层全面事件化（#4 的 DVS 化清单）；②架构两层化（#8 的监听层+思考层）；③学习栈三层化（#3 的①②③对应云端蒸馏/本地微调/运行时自适应）；④成本核算事件化（#6 的三条件账本）。四步互相咬合：事件化喂饱两层架构，两层架构决定学习栈的分层，三条件账本度量全部改造的收益。

善伦自身（最容易被忘的一层）：善伦的认知系统也要「神经形态化」——待机时保护注意力（别让无关事务唤醒），事件来了才重度处理（批量会议是大坑），交付容忍 80 分（完美主义是密集帧思维）。一人公司最大的硬件是创始人本人，最该升级的也是。

## 反例与证伪条件
迁移思路自身的证伪条件（诚实清单）：

第一，收益量化不过线。若善伦当前 API 调用量与时间开销已经极低（系统刚起步），事件化改造的收益低于改造本身的时间成本——先量化（#6 的两小时账本），再动手。为方法论而方法论是常见病。

第二，阶段错配。若善伦业务未来进入需要大规模密集计算的阶段（比如真要自研大模型、做重渲染），「事件驱动」的纪律部分失效——密集阶段就该密集打法。迁移是工具不是信仰。

第三，同构是有限度的。芯片的物理约束（功耗）与善伦的约束（时间/资金）只是部分同构；芯片省的是焦耳，善伦省的是注意力——后者的「待机功耗」无法用仪表测，只能用善伦的主观状态自省。别把迁移做成新教条。
