# 神经形态计算 · 技术思维 #10：反例与证伪

## 两性费曼 · 性一（12 岁也能懂）
- **这是什么**：像买工具前先翻到包装背面看那小段"不适用于……"——那几行字比正面广告值钱，因为它直接告诉你什么时候别掏钱。哪里不像：商品的不适用清单是厂商写给你看的，本文的清单是自己写给自己的，没有人替你检查写得对不对。

## 两性费曼 · 性二（同行可验证）
- **机制**：技术选型的第一性是比较优势，不是绝对优势——任何技术在其适用域内都可能是对的，适用域由物理约束划定，不由热度划定。神经形态的适用域由三条件（任务稀疏 / 输入是事件 / 容忍近似）划定，三个答案就是适用域的地图。证伪侧的第一性：一条判断的信息量等于它能被什么证据杀死，写不出证伪条件的判断不可检验。
- **边界数**：①大批量密集 CNN 推理、②LLM 推理（内存带宽瓶颈）为原话级警告 [二手]；⑥无任何平台有接近 CUDA 成熟度的生态 [二手]；⑦该市场已发生过整合、量产硅片保密报价 [二手]；⑤精度敏感任务为按容差条件推出 [推算]；以当前画像，八条"不该"中至少五条命中、四条"该"中至少三条不满足 [推算]。
- **反例**：①若剪枝 + 量化 + 专用 NPU 让通用硬件的稀疏推理达到同等能效，且"帧转事件"中间件足够廉价，差异化只剩历史情怀；②若 Lava / snnTorch 生态在两年内成熟到"装上即用"，#7 的成本判断与第⑥条同时过期；③元证伪——若读完十件后仍想立刻采购，说明证伪条款未生效。
- **可复现**：取一个候选任务，逐条对照八条"不该用"打勾，命中数 ≥1 即不出手；把打勾结果与半年后的实际结果一并归档，用命中率校准这张卡本身的判别力。

## 一句话（费曼层）
神经形态不是「更好的 GPU」——如果你的任务是密集的、要精确的、静态的、还想用现成框架，用它就是自找苦吃。

## 为什么这条路线被低估
唱衰不讨喜。「什么时候不该用」的清单，在技术讨论里是负资产——它不振奋、不提供「我抓住了未来」的幻觉。

但对一人公司，这份清单是全部十件里最值钱的：大团队可以在多条赛道上下注（错失的成本由分散的投资组合摊薄），一人公司输不起一次错误的技术押注。「不做什么的自由」是一人公司相对巨头少有的比较优势——本篇教善伦怎么把这个优势用在神经形态上，也用在一切新技术上。

## 第一性原理拆解
技术选型的第一性：比较优势，不是绝对优势。任何技术在它的适用域内都可能是对的——问题全在适用域之外。适用域由什么决定？由物理约束决定，不由热度决定。神经形态的适用域由三个物理约束划定：任务稀疏吗？输入是事件吗？容忍近似吗（#6 的三条件）？三个问题的答案就是适用域的地图。

证伪思维的第一性：一条思路的价值等于它能被什么证据杀死。写不出证伪条件的技术信仰是宗教——「它总是对的」等于「它无法被检验」等于「它没有信息量」。本篇给神经形态的每个「该用」场景配一个「该死」场景，让整条思路可被检验。

## 技术机制与关键事实
以下「绝对不该用」清单，每条都锚定事实包给出的证据：

① 大批量密集 CNN 推理——事实包原话级警告：GPU/NPU 更优。批量一大，GPU 并行性红利启动，神经形态的稀疏优势稀释到没有。证伪信号：你的推理任务批处理规模持续大于 1，且输入是静态图片/表格。

② LLM 推理——事实包原话级警告：内存密集，不适合。LLM 推理的瓶颈是内存带宽（权重全量流式通过计算单元），神经形态的存内计算优势在这个数据流形态下施展不开。证伪信号：你的核心负载是生成式模型推理。

③ 把标准 PyTorch/TensorFlow 代码直接搬上去——事实包列举的常见实践错误「当 GPU 用」。框架抽象不覆盖脉冲与事件，代码扔上去直接报错，没有银弹兼容层。证伪信号：团队里没人愿意重写模型代码，只想「平移」。

④ 密集静态数据任务——事实包列举的常见实践错误「用密集静态数据任务，那是 GPU 强项」。拿跑车下农田，还嫌跑车费油。证伪信号：你的数据集是成批静态文件，任务与「变化」无关。

⑤ 精度敏感任务（推论，锚定 #6 容差条件）——金融计算、医疗诊断、对误报零容忍的安防判决层。容差条件一破，三条件乘法塌方，能效神话归零，还白担了软件生态的风险。证伪信号：一次误判的业务成本高于整套系统的采购成本。

⑥ 需要成熟工具链快速交付的团队——事实包：无任何平台有接近 CUDA 成熟度的生态。装环境以周计、迁移以月计（#7）。证伪信号：项目排期按周算，且团队没有信号处理背景。

⑦ 无稳定供应商保障的量产项目——事实包：路线图风险真实存在，该市场已发生过整合；量产定价不透明（开发套件免费、量产硅片 NDA 报价）。证伪信号：产品生命周期超过芯片供应商的存续置信度。

⑧ 低估 SNN 训练难度的预算——事实包列举的常见实践错误「低估 SNN 训练难度」。训练三条路线各有死穴（#3），预算里没有「重写模型」这一项就是漏项。证伪信号：项目计划里训练时间按「微调」估。

反向清单——什么时候它可能是对的（四条全中方才考虑）：任务常开且稀疏（多数时间无事发生）；输入天然是事件流（DVS/音频 onset/传感器中断）；交付容忍近似（触发式判断，非精确输出）；团队愿意贴着金属编程且有信号处理背景（#5 的选型纪律 + #7 的生态现实）。

把这两张清单对着善伦照一遍，结论必须诚实：以善伦当前阶段——系统纯软件、任务以文本与业务逻辑为主、没有常开硬件监听场景——八条「不该」里至少五条直接命中，四条「该」里至少三条不满足。所以善伦对神经形态的正确动作是：跟踪 + 思维迁移（#9），不是采购、不是立项、更不是发文章站台。把这个结论写下来，本身就是本篇最重要的交付。

## 反例与证伪条件
本篇是证伪篇，仍需自证——本篇自己的证伪条件：

第一，如果稀疏推理在 GPU/NPU 上成熟到同等能效，且事件输入问题被「帧转事件中间件」廉价解决，神经形态的差异化只剩历史情怀——跟踪通用硬件的稀疏化路线即可。

第二，如果 Lava/snnTorch 生态在两年内成熟到「pip install 即用」的水平，#7 的成本判断与本篇第⑥条同时过期——跟踪两个项目的版本发布节奏。

第三（元证伪）：如果善伦读完十件后仍然热血地想「赶紧买块芯片」，说明这十件白写了——善伦该做的是把本篇的清单打印出来，贴在每次「要不要上新技术」的讨论开头。

## 对善伦业务的迁移点
- 决策纪律迁移（核心）：把本篇的两张清单泛化成善伦通用的「新技术入场卡」——先列「不该用的场景」，再列「该用的条件」，最后对着自己的业务画像照一遍。任何技术（不止神经形态）进来都过这张卡。一人公司的生死线不是错过机会，是抓住不该抓的机会。
- 正明 AI 系统：警惕「为用新技术而用」的引力。善伦自建系统的引力天然偏新技术（创始人的技术浪漫主义），需要制度性对冲——每次引入新组件，先写「什么证据会证明我选错了」，写不出就不引入。
- 跨境电商：供应商/工具选型同理，先看不适用场景（SLA 边界、数据归属、退出成本），再看亮点功能。善伦若选监控 SaaS，「只报变化」的功能项就该优先于「实时大屏」的展示项——这是 #6 三条件在采购端的变形。
- AI 音乐与小说：创作工具上警惕「工具先行」——先有任务结构再选工具，别为工具的先进叙事改变任务。#10 的纪律对创作者同样成立：没有任务的工具是负资产。
- 一人公司本体：善伦最大的比较优势是「精准不参与的自由」——大厂必须全赛道下注，善伦可以只打十拿九稳的仗。神经形态这张入场卡，就是善伦行使这项自由的凭证。
